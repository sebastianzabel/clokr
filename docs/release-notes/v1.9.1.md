## v1.9.1 — Vor-/Nachbereitungszeit pro Mitarbeiter

Patch-Release auf der 1.9-Linie. **Schema-Migration erforderlich** (additiv, wird beim Deploy automatisch angewandt).

### Neue Funktionen

- **Vor-/Nachbereitungszeit je Mitarbeiter:** Der Puffer für importierte Phorest-Schichten lässt sich jetzt **pro Mitarbeiter** überschreiben (Feld leer = Firmenstandard, `0` = kein Puffer). Damit tragen Mitarbeiter mit unterschiedlichen Arbeitszeit-Varianten den jeweils passenden Puffer.

### Fehlerbehebungen

- **Saldo-Genauigkeit (§615):** Der bisher nur global einstellbare Puffer konnte bei Mitarbeitern, deren Vertrag genau der buchbaren Zeit entspricht, den geplanten Dienst über die Vertrags-Wochenarbeitszeit heben und so den Saldo verzerren (Plus- oder Minusstunden je nach erfasster Zeit). Mit dem mitarbeiterspezifischen Puffer (z. B. `0`) verschwindet dieser Effekt.

### Betrieb & Migration

- **Schema-Migration** (zwei neue optionale Mitarbeiter-Felder) wird beim Start automatisch via `migrate deploy` angewandt. Rein additiv, keine Datenänderung. Bestehende Schichten übernehmen den effektiven Puffer beim nächsten Sync.
