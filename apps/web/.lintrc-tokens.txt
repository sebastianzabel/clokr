# clokr design-system v2 token lint (Issue #842)
#
# One source for the deny list. `apps/web/scripts/lint-tokens.mjs` parses the MACHINE LINES below
# (lines starting with BANNED-TOKEN / BANNED-PREFIX / BANNED-LITERAL); every line that starts with `#`
# is for humans only and is ignored by the script.
#
# Run `pnpm --filter @clokr/web lint:tokens`. CI and the pre-commit hook fail when
#   (a) a retired name below is referenced OR declared anywhere in apps/web/src
#       (tests under __tests__ and *.test.ts are not scanned; the guard tests have their own walkers), or
#   (b) a `var(--name)` has no declaration anywhere in apps/web/src (unknown names fail).
#
# Machine line grammar:
#   BANNED-TOKEN   <--name>    a custom property; identifier boundaries, so `--border` never hits `--border-strong`
#   BANNED-PREFIX  <--prefix-> every custom property that starts with the prefix
#   BANNED-LITERAL <text>      a literal string (font families, attribute names, attribute selectors); a literal
#                              that starts or ends with a word character also gets identifier boundaries
#
# The canonical token set is `apps/web/src/tokens.css`: colour roles (D-05) for three themes
# (pflaume | salz | petrol) x two modes (light | dark), selected by `data-theme` x `data-mode` on any
# element. There is no skin axis and no density axis.

# === REPLACEMENTS (cheat sheet, old -> new, D-842-11) ===
# --bg-card, --bg-elevated     -> --card
# --bg-subtle                  -> --sunk
# --bg-alt                     -> --rail
# --border                     -> --line
# --border-strong              -> --line-2
# --text-muted                 -> --text-2
# --text-faint                 -> --text-3
# --text-on-brand              -> --brand-ink
# --brand-dark                 -> --brand-hover
# --brand-light                -> --brand
# --good, --good-soft          -> --ok, --ok-soft
# --good-text, --bad-text      -> --ok, --bad (the roles are dark-capable, no separate text variant)
# --star                       -> --accent (a fill, never a text colour)
# --font-sans, --font-serif    -> --font-ui
# --font-mono                  -> --font-code for code and raw data (ids, hashes, CSV), else --font-ui
#                                 (numerals: tabular-nums is global)
# --r-sm, --r-md               -> --r-control
# --r-lg                       -> --r-card
# --r-xl                       -> --r-stage
# --shadow-xs/-sm/-md          -> --shadow
# --shadow-brand(-lg)          -> --shadow
# --shadow-lg                  -> --shadow-pop
# --pad-card                   -> --s-6
# --row-h                      -> --h-row
# --color-*, --glass-*, --radius-*, --gray-*  (v1.2) -> the role names above; there is no 1:1 map
# White text on a solid status fill -> color: var(--card)        (D-842-08)
# White text on a brand fill        -> color: var(--brand-ink)   (D-842-08)
