# === DENSITY RULE (Phase 33-02, I18N-03) ===
# Outer card padding MUST use `var(--pad-card)` so the density toggle affects it.
# Interior spacing (gaps, header/body/foot padding INSIDE a card) uses `var(--s-*)`.
#
# This is enforced because [data-density="compact"] in tokens.css flips
# --pad-card from 24px to 16px. A card that hardcodes `padding: 24px` will not
# shrink in compact mode and breaks the global density affordance.
#
# Canonical recipe (apps/web/src/app.css, COMP-01):
#   .card {
#     padding: var(--pad-card);
#     ...
#   }
#
# Modals, scrims, popovers, empty-state text and other non-card surfaces are
# exempt — they are not part of the density-aware card surface system.
